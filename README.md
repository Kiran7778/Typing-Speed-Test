# ⌨️ TypeRush

TypeRush is a modern, fast, and responsive typing speed test built with **HTML**, **CSS**, and **Vanilla JavaScript**. It provides a clean typing experience with real-time performance tracking, beautiful animations, and a modern glassmorphism interface.

Whether you're practicing daily or simply testing your typing skills, TypeRush gives you instant feedback to help you improve.

---

## ✨ Features

- ⚡ Live Words Per Minute (WPM)
- 🎯 Real-time Accuracy calculation
- ❌ Error counter
- ⏱️ Multiple timer modes (15s, 30s, 60s, 120s)
- 📄 Random typing passages
- 🏆 Performance ranking
- 📊 Detailed results screen
- 🔄 One-click restart
- ⌨️ Keyboard shortcuts
- 🌈 Modern Glassmorphism UI
- ✨ Smooth animations
- 📱 Fully responsive design
- 🎨 Gradient effects and animated background

## 🎮 How It Works

1. Select your preferred timer.
2. Click inside the typing area.
3. Start typing the displayed paragraph.
4. Watch your live statistics update.
5. Finish the test before the timer ends.
6. View your detailed performance report.
7. Restart and keep improving.
